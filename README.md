Feature Set
Account registration
User authentication (Login)
Browse available hostels
View detailed hostel information (price, description, landlord contact, location)
Search functionality for hostels
View on Map feature for hostel location and directions 
Onboarding screen for new users
Responsive UI built with Jetpack Compose
Dark Mode support
Profile Editing supported

Technical Stack

The application follows the MVVM (Model-View-ViewModel) architecture:
Model: Handles data structures and data sources
View: UI built using Jetpack Compose
ViewModel: Manages UI state and business logic
Jetpack Compose
Navigation Component
Firebase
ViewModel & State Management (remember)
Material 3 Design System
